Each guide covers one job or tool, from setup to a first run. Pick a section by what you are doing: giving an agent a desktop, running CI jobs or Docker, evaluating or training agents, or running, building, or hosting an agent. To let an agent start its own sandboxes when a task needs one, connect it through the [MCP Server](/integrations/mcp).
