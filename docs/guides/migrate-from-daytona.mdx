## Ready to switch

Pick how you want to migrate. Do it yourself step by step, or give the prompt to a coding agent and let it change your code.

<Step title="Install the SDK and set your API key">

Install the Superserve SDK next to Daytona. Set `SUPERSERVE_API_KEY` in your environment and CI secrets.

<CodeGroup>
```bash TypeScript
npm install @superserve/sdk
export SUPERSERVE_API_KEY=ss_live_...
```

```bash Python
pip install superserve
export SUPERSERVE_API_KEY=ss_live_...
```

<Step title="Map the API">

The main changes: a Daytona snapshot becomes a Superserve template, every sandbox needs a `name`, commands move from `process` to `commands`, and an idle sandbox pauses instead of stopping.

<Tabs>
<Tab title="TypeScript">

| Task | Daytona | Superserve |
| --- | --- | --- |
| Create | `daytona.create({ snapshot, envVars, labels, autoStopInterval })` | `Sandbox.create({ name, fromTemplate, envVars, metadata, idleTimeoutSeconds })`. `name` is required. |
| Image | `daytona.snapshot.create({ name, image: Image.debianSlim().pipInstall([...]) })` | `Template.create({ name, from: img, steps: [{ run }] })`, built once. Then `fromTemplate: name`. |
| Reconnect | `daytona.get(idOrName)`, then `sandbox.start()` if it is stopped | `Sandbox.connect(id)`. Resumes a paused sandbox automatically. |
| Run a command | `sandbox.process.executeCommand(cmd, cwd, env, timeout)` returns `exitCode` and `result` | `sbx.commands.run(cmd, { cwd, env, timeoutMs })` returns `exitCode`, `stdout` and `stderr` |
| Run code | `sandbox.process.codeRun(code)` | `sbx.files.write("/home/user/main.py", code)`, then `sbx.commands.run("python3 /home/user/main.py")` |
| Background process | `sandbox.process.createSession(id)`, then `executeSessionCommand(id, { command, runAsync: true })` | `sbx.commands.spawn(cmd)` |
| Files | `sandbox.fs.uploadFile(Buffer.from(data), path)` / `downloadFile(path)` | `sbx.files.write(path, data)` / `read(path)`. The path comes first. |
| Save state | `sandbox.createSnapshot(name)` or `sandbox.fork()`. Disk only. | `sbx.snapshot()`, then `Sandbox.create({ name, fromSnapshot })`. Saves memory and disk; forks keep running processes. |
| Stop and start | `sandbox.stop()` / `sandbox.start()`. Stop ends running processes. | `sbx.pause()` / `sbx.resume()`. Pause keeps memory and running processes. |
| Idle timeout | `autoStopInterval` in minutes. Default 15. Stops the sandbox. | `idleTimeoutSeconds`. Off by default. Pauses the sandbox. |
| Auto-delete | `autoDeleteInterval` in minutes after stop, or `ephemeral: true` | `autoDeleteSeconds` after pause. `0` deletes the sandbox when it pauses. |
| Env vars and secrets | `envVars`, `secrets: { ENV_VAR: "secret-name" }` | `envVars` on create, `env` per command, `secrets: { ENV_VAR: "secret-name" }`. See [Secrets](/secrets/overview). |
| Public URL | `sandbox.getPreviewLink(port)` returns `url` and `token` | `await sbx.publishPreviewPort(port)`, then `sbx.getPreviewUrl(port)`. New sandboxes route only published ports. See [Preview URLs](/sandbox/preview-urls). |
| List and delete | `daytona.list({ labels })` / `sandbox.delete()` | `Sandbox.list({ metadata })` / `sbx.kill()` |

</Tab>
<Tab title="Python">

| Task | Daytona | Superserve |
| --- | --- | --- |
| Create | `daytona.create(CreateSandboxFromSnapshotParams(snapshot=, env_vars=, labels=, auto_stop_interval=))` | `Sandbox.create(name=, from_template=, env_vars=, metadata=, idle_timeout_seconds=)`. `name` is required. |
| Image | `daytona.snapshot.create(CreateSnapshotParams(name=, image=Image.debian_slim().pip_install(...)))` | `Template.create(name=, from_=img, steps=[RunStep(run=...)])`, built once. Then `from_template=name`. |
| Reconnect | `daytona.get(id_or_name)`, then `sandbox.start()` if it is stopped | `Sandbox.connect(id)`. Resumes a paused sandbox automatically. |
| Run a command | `sandbox.process.exec(cmd, cwd=, env=, timeout=)` returns `exit_code` and `result` | `sbx.commands.run(cmd, cwd=, env=, timeout_seconds=)` returns `exit_code`, `stdout` and `stderr` |
| Run code | `sandbox.process.code_run(code)` | `sbx.files.write("/home/user/main.py", code)`, then `sbx.commands.run("python3 /home/user/main.py")` |
| Background process | `sandbox.process.create_session(id)`, then `execute_session_command(id, SessionExecuteRequest(command=, run_async=True))` | `await sbx.commands.spawn(cmd)` on `AsyncSandbox` |
| Files | `sandbox.fs.upload_file(data, path)` / `download_file(path)` | `sbx.files.write(path, data)` / `read(path)`. The path comes first. |
| Save state | `sandbox.create_snapshot(name)` or `sandbox.fork()`. Disk only. | `sbx.snapshot()`, then `Sandbox.create(name=, from_snapshot=)`. Saves memory and disk; forks keep running processes. |
| Stop and start | `sandbox.stop()` / `sandbox.start()`. Stop ends running processes. | `sbx.pause()` / `sbx.resume()`. Pause keeps memory and running processes. |
| Idle timeout | `auto_stop_interval` in minutes. Default 15. Stops the sandbox. | `idle_timeout_seconds`. Off by default. Pauses the sandbox. |
| Auto-delete | `auto_delete_interval` in minutes after stop, or `ephemeral=True` | `auto_delete_seconds` after pause. `0` deletes the sandbox when it pauses. |
| Env vars and secrets | `env_vars`, `secrets={"ENV_VAR": "secret-name"}` | `env_vars` on create, `env` per command, `secrets={"ENV_VAR": "secret-name"}`. See [Secrets](/secrets/overview). |
| Public URL | `sandbox.get_preview_link(port)` returns `url` and `token` | `sbx.publish_preview_port(port)`, then `sbx.get_preview_url(port)`. New sandboxes route only published ports. See [Preview URLs](/sandbox/preview-urls). |
| List and delete | `daytona.list(ListSandboxesQuery(labels=))` / `sandbox.delete()` | `Sandbox.list(metadata=)` / `sbx.kill()` |

<Step title="Update your code">

Build the template once. Then replace the Daytona client with `Sandbox`, add a `name`, and convert intervals from minutes to seconds.

<CodeGroup>
```ts Before (Daytona)
import { Daytona, Image } from "@daytona/sdk"

const daytona = new Daytona()
await daytona.snapshot.create({
  name: "my-snapshot",
  image: Image.debianSlim("3.12").pipInstall(["pytest"]),
})

const sandbox = await daytona.create({
  snapshot: "my-snapshot",
  envVars: { MODE: "ci" },
  autoStopInterval: 10,
})
await sandbox.process.executeCommand("pytest")
const { url } = await sandbox.getPreviewLink(8000)
const fork = await sandbox.fork({ name: "fork" })
```

```ts After (Superserve)
import { Sandbox, Template } from "@superserve/sdk"

// Build once. Sandboxes then start from the template.
const tpl = await Template.create({
  name: "my-tpl",
  from: "python:3.12",
  steps: [{ run: "pip install pytest" }],
})
await tpl.waitUntilReady()

const sbx = await Sandbox.create({
  name: "ci-run",
  fromTemplate: "my-tpl",
  envVars: { MODE: "ci" },
  idleTimeoutSeconds: 600,
})
await sbx.commands.run("pytest")
await sbx.publishPreviewPort(8000)
const url = sbx.getPreviewUrl(8000)
const snap = await sbx.snapshot()
const fork = await Sandbox.create({ name: "fork", fromSnapshot: snap })
```

```python Before (Daytona, Python)
from daytona import (
    CreateSandboxFromSnapshotParams,
    CreateSnapshotParams,
    Daytona,
    Image,
)

daytona = Daytona()
daytona.snapshot.create(
    CreateSnapshotParams(
        name="my-snapshot",
        image=Image.debian_slim("3.12").pip_install("pytest"),
    )
)

sandbox = daytona.create(
    CreateSandboxFromSnapshotParams(
        snapshot="my-snapshot",
        env_vars={"MODE": "ci"},
        auto_stop_interval=10,
    )
)
sandbox.process.exec("pytest")
url = sandbox.get_preview_link(8000).url
fork = sandbox.fork(name="fork")
```

```python After (Superserve, Python)
from superserve import RunStep, Sandbox, Template

# Build once. Sandboxes then start from the template.
tpl = Template.create(
    name="my-tpl",
    from_="python:3.12",
    steps=[RunStep(run="pip install pytest")],
)
tpl.wait_until_ready()

sbx = Sandbox.create(
    name="ci-run",
    from_template="my-tpl",
    env_vars={"MODE": "ci"},
    idle_timeout_seconds=600,
)
sbx.commands.run("pytest")
sbx.publish_preview_port(8000)
url = sbx.get_preview_url(8000)
snap = sbx.snapshot()
fork = Sandbox.create(name="fork", from_snapshot=snap)
```

<Step title="Move existing sandboxes with the migration script">

The script copies a directory from each started Daytona sandbox into a new Superserve sandbox. It does not change or delete your Daytona sandboxes. Run it with both `DAYTONA_API_KEY` and `SUPERSERVE_API_KEY` set. Start a stopped Daytona sandbox first to include it.

<CodeGroup>
```ts migrate-from-daytona.ts
import { Daytona, SandboxState } from "@daytona/sdk"
import { Sandbox } from "@superserve/sdk"

const SRC = "/home/daytona" // directory to copy from each Daytona sandbox
const DST = "/home/user" // directory to copy into in Superserve
const TEMPLATE = "superserve/base" // or the template you built from your Daytona snapshot

const daytona = new Daytona()
for await (const src of daytona.list({ states: [SandboxState.STARTED] })) {
  const tar = await src.process.executeCommand(
    `tar czf /tmp/state.tgz -C ${SRC} . 2>&1`,
  )
  if (tar.exitCode !== 0) {
    console.error(`${src.id}: archive failed: ${tar.result}`)
    process.exitCode = 1
    continue
  }
  const tgz = await src.fs.downloadFile("/tmp/state.tgz")

  const dst = await Sandbox.create({
    name: `from-daytona-${src.id}`,
    fromTemplate: TEMPLATE,
    metadata: { ...src.labels, migrated_from: src.id },
  })
  await dst.files.write("/tmp/state.tgz", tgz)
  const out = await dst.commands.run(`tar xzf /tmp/state.tgz -C ${DST}`)
  if (out.exitCode !== 0) {
    console.error(`${src.id}: copy failed: ${out.stderr}`)
    process.exitCode = 1
    continue
  }
  console.log(`${src.id} -> ${dst.id}`)
}
```

```python migrate_from_daytona.py
import sys

from daytona import Daytona, ListSandboxesQuery, SandboxState
from superserve import Sandbox

SRC = "/home/daytona"  # directory to copy from each Daytona sandbox
DST = "/home/user"  # directory to copy into in Superserve
TEMPLATE = "superserve/base"  # or the template you built from your Daytona snapshot
failed = False

daytona = Daytona()
for src in daytona.list(ListSandboxesQuery(states=[SandboxState.STARTED])):
    tar = src.process.exec(f"tar czf /tmp/state.tgz -C {SRC} . 2>&1")
    if tar.exit_code != 0:
        print(f"{src.id}: archive failed: {tar.result}", file=sys.stderr)
        failed = True
        continue
    tgz = src.fs.download_file("/tmp/state.tgz")

    dst = Sandbox.create(
        name=f"from-daytona-{src.id}",
        from_template=TEMPLATE,
        metadata={**src.labels, "migrated_from": src.id},
    )
    dst.files.write("/tmp/state.tgz", tgz)
    out = dst.commands.run(f"tar xzf /tmp/state.tgz -C {DST}")
    if out.exit_code != 0:
        print(f"{src.id}: copy failed: {out.stderr}", file=sys.stderr)
        failed = True
        continue
    print(f"{src.id} -> {dst.id}")

sys.exit(1 if failed else 0)
```
</CodeGroup>

The script copies files. Start your services in the new sandbox, then take a Superserve [snapshot](/sandbox/snapshots) to save memory, processes and disk together.

## Known differences

| Area | What to do |
| --- | --- |
| Snapshots | A Daytona snapshot is a base image for new sandboxes. In Superserve that is a template. A Superserve snapshot saves the memory and disk of one sandbox. |
| Idle behavior | Daytona stops an idle sandbox after 15 minutes by default, which ends its processes. Superserve has no idle timeout by default. Set `idleTimeoutSeconds` to pause an idle sandbox and keep its processes. Call `kill()` or set `autoDeleteSeconds` if you want it gone. |
| Commands | `commands.run` returns `stdout` and `stderr` separately and does not throw on a nonzero exit code. Check `exitCode` / `exit_code`. |
| Resources | Set `vcpu` and `memoryMib` on the template, not on the sandbox. Memory is in MiB, not GiB. |
| Home directory | Daytona sandboxes use `/home/daytona`. Superserve sandboxes use `/home/user`. Update hard-coded paths. |
| Preview ports | New sandboxes route only published ports. Call `publishPreviewPort` before you use a preview URL. Serve on a port from 1024 to 65535. |
| Process state | The migration script moves files, not memory. Take a Superserve snapshot after you restart services. |
