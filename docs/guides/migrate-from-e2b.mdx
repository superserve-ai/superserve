Pick how you want to migrate. Do it yourself step by step, or give the prompt to a coding agent and let it change your code.

<Step title="Map the API">

Most calls keep their names. The main changes: every sandbox needs a `name`, timeouts are in seconds, and a timeout pauses the sandbox instead of killing it.

<Tabs>
<Tab title="TypeScript">

| Task | E2B | Superserve |
| --- | --- | --- |
| Create | `Sandbox.create("tpl", { timeoutMs, envs, metadata })` | `Sandbox.create({ name, fromTemplate, timeoutSeconds, envVars, metadata })`. `name` is required. |
| Reconnect | `Sandbox.connect(id)` | `Sandbox.connect(id)`. Resumes a paused sandbox automatically. |
| Run a command | `sbx.commands.run(cmd, { envs, cwd, timeoutMs })` | `sbx.commands.run(cmd, { env, cwd, timeoutMs })` |
| Background process | `sbx.commands.run(cmd, { background: true })` | `sbx.commands.spawn(cmd)` |
| Files | `sbx.files.write(path, data)` / `read(path)` | `sbx.files.write(path, data)` / `read(path)` |
| Templates | `Template().fromImage(img)` and `Template.build()` | `Template.create({ name, from: img, steps })` |
| Snapshot | `sbx.createSnapshot()`, then `Sandbox.create(snapshotId)` | `sbx.snapshot()`, then `Sandbox.create({ name, fromSnapshot })`. Saves memory and disk; forks keep running processes. |
| Pause and resume | `sbx.pause()` / `sbx.connect()` | `sbx.pause()` / `sbx.resume()` |
| Timeout | `sbx.setTimeout(ms)`. Kills by default. | `sbx.update({ timeoutSeconds })`. Pauses. Also `idleTimeoutSeconds`. |
| Env vars | `envs` | `envVars` on create, `env` per command, `secrets` for API keys |
| Public URL | `sbx.getHost(port)` | `await sbx.publishPreviewPort(port)`, then `sbx.getPreviewUrl(port)`. New sandboxes route only published ports. See [Preview URLs](/sandbox/preview-urls). |
| Public URL with auth | `network: { allowPublicTraffic: false }`, then send `sbx.trafficAccessToken` | `await sbx.publishPreviewPort(port, { access: "private" })`, then `sbx.getPreviewUrl(port)`. For the token, use `await sbx.getPreviewToken(port)` (send `token` in the returned `header`) or `await sbx.getSignedPreviewUrl(port)` for a browser. |
| List and kill | `Sandbox.list()` / `sbx.kill()` | `Sandbox.list()` / `sbx.kill()` |

</Tab>

<Step title="Update your code">

Change the import, add a `name`, and convert timeouts to seconds.

<CodeGroup>
```ts E2B
import { Sandbox } from "e2b"

const sbx = await Sandbox.create("my-tpl", {
  timeoutMs: 600_000,
  envs: { MODE: "ci" },
})
await sbx.commands.run("npm test")
const snap = await sbx.createSnapshot()
const fork = await Sandbox.create(snap.snapshotId)
```

```ts Superserve
import { Sandbox } from "@superserve/sdk"

const sbx = await Sandbox.create({
  name: "ci-run",
  fromTemplate: "my-tpl",
  timeoutSeconds: 600,
  envVars: { MODE: "ci" },
})
// run() stops a command after 30 s by default
await sbx.commands.run("npm test", { timeoutMs: 10 * 60 * 1000 })
const snap = await sbx.snapshot()
const fork = await Sandbox.create({ name: "fork", fromSnapshot: snap })
```
</CodeGroup>

<CodeGroup>
```python E2B
from e2b import Sandbox

sbx = Sandbox.create("my-tpl", timeout=600, envs={"MODE": "ci"})
sbx.commands.run("pytest")
snap = sbx.create_snapshot()
fork = Sandbox.create(snap.snapshot_id)
```

```python Superserve
from superserve import Sandbox

sbx = Sandbox.create(
    name="ci-run",

    env_vars={"MODE": "ci"},

snap = sbx.snapshot()
```

<Step title="Move existing sandboxes with the migration script">

The script copies `/home/user` from each E2B sandbox into a new Superserve sandbox. It does not change or delete your E2B sandboxes; it removes only the temporary archive. If a copy fails, the script deletes the new Superserve sandbox. Run it with both `E2B_API_KEY` and `SUPERSERVE_API_KEY` set.

<CodeGroup>
```ts migrate-from-e2b.ts
import { Sandbox as E2B } from "e2b"
import { Sandbox } from "@superserve/sdk"

// Map each E2B template ID to the Superserve template that replaces it.
// Sandboxes from other templates start from superserve/base.
const TEMPLATES: Record<string, string> = { "my-e2b-template-id": "my-tpl" }
const DIR = "/home/user"
const TIMEOUT_MS = 10 * 60 * 1000 // limit for each archive, upload and extract

const pages = E2B.list()
while (pages.hasNext) {
  for (const info of await pages.nextItems()) {
    const src = await E2B.connect(info.sandboxId)
    let tgz: Uint8Array
    try {
      // commands.run throws when tar exits with a nonzero code.
      await src.commands.run(`tar czf /tmp/state.tgz -C ${DIR} .`, {
        timeoutMs: TIMEOUT_MS,
      })
      tgz = await src.files.read("/tmp/state.tgz", { format: "bytes" })
    } catch (err) {
      console.error(`${info.sandboxId}: archive failed: ${err}`)
      process.exitCode = 1
      continue
    } finally {
      // Remove the temporary archive from the source, also after a failure.
      await src.commands
        .run("rm -f /tmp/state.tgz")
        .catch(() =>
          console.error(`${info.sandboxId}: remove /tmp/state.tgz by hand`),
        )
    }

    const dst = await Sandbox.create({
      name: `from-e2b-${info.sandboxId}`,
      fromTemplate: TEMPLATES[info.templateId] ?? "superserve/base",
      metadata: { ...info.metadata, migrated_from: info.sandboxId },
    })
    try {
      await dst.files.write("/tmp/state.tgz", tgz, { timeoutMs: TIMEOUT_MS })
      const out = await dst.commands.run(
        `tar xzf /tmp/state.tgz -C ${DIR} && rm /tmp/state.tgz`,
        { timeoutMs: TIMEOUT_MS },
      )
      if (out.exitCode !== 0) throw new Error(out.stderr)
    } catch (err) {
      console.error(`${info.sandboxId}: copy failed: ${err}`)
      process.exitCode = 1
      // Delete the new sandbox so a failed copy does not keep running.
      await dst
        .kill()
        .catch(() =>
          console.error(`${info.sandboxId}: delete ${dst.id} by hand`),
        )
      continue
    }
    console.log(`${info.sandboxId} -> ${dst.id}`)
  }
}
```

```python migrate_from_e2b.py
import sys

from e2b import Sandbox as E2B
from superserve import Sandbox

# Map each E2B template ID to the Superserve template that replaces it.
# Sandboxes from other templates start from superserve/base.
TEMPLATES = {"my-e2b-template-id": "my-tpl"}
DIR = "/home/user"
TIMEOUT_SECONDS = 10 * 60  # limit for each archive, upload and extract
failed = False

pages = E2B.list()
while pages.has_next:
    for info in pages.next_items():
        src = E2B.connect(info.sandbox_id)
        try:
            # commands.run raises when tar exits with a nonzero code.
            src.commands.run(
                f"tar czf /tmp/state.tgz -C {DIR} .", timeout=TIMEOUT_SECONDS
            )
            tgz = src.files.read("/tmp/state.tgz", format="bytes")
        except Exception as err:
            print(f"{info.sandbox_id}: archive failed: {err}", file=sys.stderr)
            failed = True
            continue
        finally:
            # Remove the temporary archive from the source, also after a failure.
            try:
                src.commands.run("rm -f /tmp/state.tgz")
            except Exception:
                print(
                    f"{info.sandbox_id}: remove /tmp/state.tgz by hand", file=sys.stderr
                )

        dst = Sandbox.create(
            name=f"from-e2b-{info.sandbox_id}",
            from_template=TEMPLATES.get(info.template_id, "superserve/base"),
            metadata={**info.metadata, "migrated_from": info.sandbox_id},
        )
        try:
            dst.files.write("/tmp/state.tgz", bytes(tgz), timeout=TIMEOUT_SECONDS)
            out = dst.commands.run(
                f"tar xzf /tmp/state.tgz -C {DIR} && rm /tmp/state.tgz",
                timeout_seconds=TIMEOUT_SECONDS,
            )
            if out.exit_code != 0:
                raise RuntimeError(out.stderr)
        except Exception as err:
            print(f"{info.sandbox_id}: copy failed: {err}", file=sys.stderr)
            failed = True
            # Delete the new sandbox so a failed copy does not keep running.
            try:
                dst.kill()
            except Exception:
                print(f"{info.sandbox_id}: delete {dst.id} by hand", file=sys.stderr)
            continue
        print(f"{info.sandbox_id} -> {dst.id}")

sys.exit(1 if failed else 0)
```
</CodeGroup>

Each archive, upload and extract can take up to 10 minutes. For large directories or slow connections, raise `TIMEOUT_MS` / `TIMEOUT_SECONDS`.

<Warning>
The script copies files only. Running processes and memory do not move. Start your services again in the new sandbox, then take a Superserve [snapshot](/sandbox/snapshots) to keep that state.
</Warning>

## Known differences

| Area | What to do |
| --- | --- |
| Timeout behavior | E2B kills a sandbox at its timeout by default. Superserve pauses it and stops compute billing. Call `kill()` or set `autoDeleteSeconds` if you want it gone. |
| Commands | Without a timeout, `run()` stops a command after 30 seconds. Set `timeoutMs` / `timeout_seconds` on installs, builds and tests. |
| Images | Build an image into a template with `Template.create` first, then create sandboxes from the template. |
| Preview ports | New sandboxes route only published ports, and a new port is public by default. Call `publishPreviewPort` before you use a preview URL. Publish with `access: "private"` and send a preview token to keep a port protected. Ports 1024 to 65535 only: move a server on port 80 or 443 to a higher port. |
| Process state | The migration script moves files, not memory. Take a Superserve snapshot after you restart services. |
