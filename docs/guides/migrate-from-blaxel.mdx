<Step title="Map the API">

The main changes: a Blaxel image becomes a template, every sandbox gets an `id` that you keep, `process.exec` becomes `commands.run`, and you choose when an idle sandbox pauses. The Blaxel Python SDK is async. Use `AsyncSandbox` to keep `await`, or `Sandbox` for blocking calls.

<Tabs>
<Tab title="TypeScript">

| Task | Blaxel | Superserve |
| --- | --- | --- |
| Create | `SandboxInstance.create({ name, image, envs })` or `createIfNotExists(...)` | `Sandbox.create({ name, fromTemplate, envVars, metadata })`. Keep `sbx.id` and reconnect with `Sandbox.connect(id)`. |
| Find a sandbox | `SandboxInstance.get(name)` / `getByExternalId(id)` | `Sandbox.connect(id)`, or set your key in `metadata` and use `Sandbox.list({ metadata })` |
| Image | `image: "blaxel/base-image:latest"` or a custom image from a Dockerfile | `Template.create({ name, from: img, steps: [{ run }] })`, built once. Then `fromTemplate: name`. The default `superserve/base` template has Node.js, Python and Git. |
| Memory | `memory: 4096` on the sandbox | `memoryMib` and `vcpu` on the template |
| Run a command | `sandbox.process.exec({ command, workingDir, env, waitForCompletion: true })` | `sbx.commands.run(cmd, { cwd, env, timeoutMs })` returns `exitCode`, `stdout` and `stderr` |
| Stream output | `sandbox.process.exec({ command, onLog })` or `process.streamLogs(name, { onStdout })` | `sbx.commands.run(cmd, { onStdout, onStderr })` |
| Background process | `sandbox.process.exec({ name, command })`, then `process.wait(name)` / `process.kill(name)` | `sbx.commands.spawn(cmd)`, then `wait()` / `kill()` |
| Files | `sandbox.fs.write(path, content)` / `read(path)` / `readBinary(path)` | `sbx.files.write(path, data)` / `readText(path)` / `read(path)` |
| Save state | `sandbox.snapshots.create(name)` / `sandbox.fork(name)` | `sbx.snapshot()`, then `Sandbox.create({ name, fromSnapshot })`. Saves memory and disk; forks keep running processes. |
| Idle and standby | Standby after a few seconds with no connection. `keepAlive: true` on a process to stay awake. | `idleTimeoutSeconds`. Off by default. Pauses the sandbox and keeps memory, processes and disk. `sbx.pause()` / `sbx.resume()` at any time. |
| Expiration | `ttl`, `expires` or `lifecycle.expirationPolicies` (`ttl-idle`, `ttl-max-age`) | `autoDeleteSeconds` deletes a sandbox after it is paused for that long. Use it with `idleTimeoutSeconds` for `ttl-idle`, or with `timeoutSeconds` (pause after that much active time) for `ttl-max-age`. `0` deletes on pause. See [Lifecycle](/sandbox/lifecycle#auto-delete). |
| Env vars and secrets | `envs: [{ name, value }]`, `env` per process. Credentials added by `network.proxy.routing` headers. | `envVars` on create, `env` per command, `secrets: { ENV_VAR: "secret-name" }`. The real key never enters the sandbox. See [Secrets](/secrets/overview). |
| Network rules | `network: { allowedDomains, forbiddenDomains }` | `allowedDomains` becomes `network: { allowOut: ["1.1.1.1/32", "8.8.8.8/32", ...domains], denyOut: ["0.0.0.0/0"] }`. The two IPs are the sandbox DNS resolvers. Without them, no name resolves. `denyOut` takes only IPs and CIDRs, so `forbiddenDomains` has no direct match. Check those rules by hand, or block the domains with an allowlist that leaves them out. See [Network rules](/sandbox/networking). |
| Volumes | `volumes: [{ name, mountPath }]` | Mount an [Archil](/storage/archil) filesystem or a [cloud bucket](/storage/cloud-buckets) from a template. |
| Public URL | `sandbox.previews.createIfNotExists({ metadata: { name }, spec: { port, public: false } })`, then `preview.tokens.create(expiresAt)` | `await sbx.publishPreviewPort(port, { access: "private" })`, then `sbx.getPreviewUrl(port)`. For the token, use `await sbx.getPreviewToken(port)` (send `token` in the returned `header`) or `await sbx.getSignedPreviewUrl(port)` for a browser. See [Preview URLs](/sandbox/preview-urls). |
| List and delete | `SandboxInstance.list()` / `SandboxInstance.delete(name)` | `Sandbox.list({ metadata })` / `sbx.kill()` |

<Step title="Update your code">

Replace `SandboxInstance` with `Sandbox`, use a template instead of an image, and change paths under `/blaxel` to `/home/user`.

<CodeGroup>
```ts Blaxel
import { SandboxInstance } from "@blaxel/core"

const sandbox = await SandboxInstance.createIfNotExists({
  name: "ci-run",
  image: "blaxel/base-image:latest",
  envs: [{ name: "MODE", value: "ci" }],
  lifecycle: {
    expirationPolicies: [{ type: "ttl-idle", value: "24h", action: "delete" }],
  },
})
await sandbox.process.exec({
  command: "git clone --depth 1 https://github.com/your-org/your-app.git /blaxel/app",
  waitForCompletion: true,
})
const result = await sandbox.process.exec({
  command: "npm install && npm test",
  workingDir: "/blaxel/app",
  waitForCompletion: true,
})
console.log(result.stdout)
const preview = await sandbox.previews.createIfNotExists({
  metadata: { name: "app" },
  spec: { port: 3000, public: false },
})
const token = await preview.tokens.create(new Date(Date.now() + 86_400_000))
const url = `${preview.url}?bl_preview_token=${token.value}`
const fork = await sandbox.fork("fork")
```

```ts Superserve
import { Sandbox } from "@superserve/sdk"

const sbx = await Sandbox.create({
  name: "ci-run",
  fromTemplate: "superserve/base",
  envVars: { MODE: "ci" },
  idleTimeoutSeconds: 60,
  autoDeleteSeconds: 24 * 60 * 60,

  "git clone --depth 1 https://github.com/your-org/your-app.git /home/user/app",
```

<Step title="Move existing sandboxes with the migration script">

The script copies `/blaxel` from each deployed Blaxel sandbox into `/home/user` in a new Superserve sandbox. A sandbox on standby resumes when the script calls it. The script does not change or delete your Blaxel sandboxes; it removes only the temporary archive. If a copy fails, the script deletes the new Superserve sandbox. Run it with `BL_WORKSPACE`, `BL_API_KEY` and `SUPERSERVE_API_KEY` set. Unarchive an archived sandbox first to include it.

<CodeGroup>
```ts migrate-from-blaxel.ts
import { SandboxInstance } from "@blaxel/core"
import { Sandbox } from "@superserve/sdk"

const SRC = "/blaxel" // directory to copy from each Blaxel sandbox
const DST = "/home/user" // directory to copy into in Superserve
const TEMPLATE = "superserve/base" // or the template you built from your Blaxel image
const TIMEOUT_MS = 10 * 60 * 1000 // limit for each archive, upload and extract

// Stop tar if wait() ran out of time (wait does not stop it), then delete the archive.
async function removeArchive(src: SandboxInstance, name: string, pid?: string) {
  try {
    if (pid) {
      await src.process.kill(pid).catch(() => {}) // tar may have exited already
      await src.process.wait(pid, { maxWait: 30_000 })
    }
    const rm = await src.process.exec({
      command: "rm -f /tmp/state.tgz",
      waitForCompletion: true,
    })
    if (rm.exitCode !== 0) throw new Error(rm.logs)
  } catch {
    console.error(`${name}: remove /tmp/state.tgz by hand`)
  }
}

for await (const src of await SandboxInstance.list({ limit: 50 })) {
  const name = src.metadata.name
  if (src.status !== "DEPLOYED") continue
  let tgz: Uint8Array
  let running: string | undefined // pid of a tar that has not exited
  try {
    const { pid } = await src.process.exec({
      command: `tar czf /tmp/state.tgz -C ${SRC} .`,
    })
    running = pid
    const tar = await src.process.wait(pid, { maxWait: TIMEOUT_MS })
    running = undefined
    if (tar.exitCode !== 0) throw new Error(tar.logs)
    const blob = await src.fs.readBinary("/tmp/state.tgz")
    tgz = new Uint8Array(await blob.arrayBuffer())
  } catch (err) {
    console.error(`${name}: archive failed: ${err}`)
    process.exitCode = 1
    continue
  } finally {
    await removeArchive(src, name, running)
  }

  const dst = await Sandbox.create({
    name: `from-blaxel-${name}`,
    fromTemplate: TEMPLATE,
    metadata: { migrated_from: name },
  })
  try {
    await dst.files.write("/tmp/state.tgz", tgz, { timeoutMs: TIMEOUT_MS })
    const out = await dst.commands.run(
      `tar xzf /tmp/state.tgz -C ${DST} && rm /tmp/state.tgz`,
      { timeoutMs: TIMEOUT_MS },
    )
    if (out.exitCode !== 0) throw new Error(out.stderr)
  } catch (err) {
    console.error(`${name}: copy failed: ${err}`)
    process.exitCode = 1
    // Delete the new sandbox so a failed copy does not keep running.
    await dst
      .kill()
      .catch(() => console.error(`${name}: delete ${dst.id} by hand`))
    continue
  }
  console.log(`${name} -> ${dst.id}`)
}
```

```python migrate_from_blaxel.py
import asyncio
import contextlib
import sys

from blaxel.core import SandboxInstance
from superserve import AsyncSandbox

SRC = "/blaxel"  # directory to copy from each Blaxel sandbox
DST = "/home/user"  # directory to copy into in Superserve
TEMPLATE = "superserve/base"  # or the template you built from your Blaxel image
TIMEOUT_SECONDS = 10 * 60  # limit for each archive, upload and extract


async def remove_archive(src: SandboxInstance, name: str, pid: str | None) -> None:
    """Stop tar if wait() ran out of time (wait does not stop it), then delete it."""
    try:
        if pid:
            with contextlib.suppress(Exception):  # tar may have exited already
                await src.process.kill(pid)
            await src.process.wait(pid, max_wait=30_000)
        rm = await src.process.exec(
            {"command": "rm -f /tmp/state.tgz", "wait_for_completion": True}
        )
        if rm.exit_code != 0:
            raise RuntimeError(rm.logs)
    except Exception:
        print(f"{name}: remove /tmp/state.tgz by hand", file=sys.stderr)


async def main() -> int:
    failed = False
    page = await SandboxInstance.list(limit=50)
    async for src in page.auto_paging_iter():
        name = src.metadata.name
        if src.status != "DEPLOYED":
            continue
        running: str | None = None  # pid of a tar that has not exited
        try:
            started = await src.process.exec(
                {"command": f"tar czf /tmp/state.tgz -C {SRC} ."}
            )
            running = started.pid
            tar = await src.process.wait(started.pid, max_wait=TIMEOUT_SECONDS * 1000)
            running = None
            if tar.exit_code != 0:
                raise RuntimeError(tar.logs)
            tgz = await src.fs.read_binary("/tmp/state.tgz")
        except Exception as err:
            print(f"{name}: archive failed: {err}", file=sys.stderr)
            failed = True
            continue
        finally:
            await remove_archive(src, name, running)

        dst = await AsyncSandbox.create(
            name=f"from-blaxel-{name}",
            from_template=TEMPLATE,
            metadata={"migrated_from": name},
        )
        try:
            await dst.files.write("/tmp/state.tgz", tgz, timeout=TIMEOUT_SECONDS)
            out = await dst.commands.run(
                f"tar xzf /tmp/state.tgz -C {DST} && rm /tmp/state.tgz",
                timeout_seconds=TIMEOUT_SECONDS,
            )
            if out.exit_code != 0:
                raise RuntimeError(out.stderr)
        except Exception as err:
            print(f"{name}: copy failed: {err}", file=sys.stderr)
            failed = True
            # Delete the new sandbox so a failed copy does not keep running.
            try:
                await dst.kill()
            except Exception:
                print(f"{name}: delete {dst.id} by hand", file=sys.stderr)
            continue
        print(f"{name} -> {dst.id}")
    return 1 if failed else 0


sys.exit(asyncio.run(main()))
```
</CodeGroup>

If your image uses a different working directory, set `SRC` to it. Each archive, upload and extract can take up to 10 minutes. If tar runs longer, the script stops it and skips that sandbox. For large directories or slow connections, raise `TIMEOUT_MS` / `TIMEOUT_SECONDS`.

The script copies files. Start your services in the new sandbox, then take a Superserve [snapshot](/sandbox/snapshots) to save memory, processes and disk together.

## Known differences

| Area | What to do |
| --- | --- |
| Credentials | Blaxel reads `BL_WORKSPACE` and `BL_API_KEY`. Superserve reads `SUPERSERVE_API_KEY`. |
| Sandbox ID | Blaxel finds a sandbox by its name. Superserve gives each sandbox an `id` on create. Store it, or set your key in `metadata` and find the sandbox with `Sandbox.list({ metadata })`. |
| Idle behavior | Blaxel puts a sandbox with no connection on standby after a few seconds. By default, a Superserve sandbox does not pause for being idle. Set `idleTimeoutSeconds` to pause it with its memory, processes and disk. |
| Commands | `process.exec` returns when the process starts unless you set `waitForCompletion`. `commands.run` waits for the command and returns `stdout` and `stderr`. It does not throw on a nonzero exit code. Check `exitCode` / `exit_code`. Without a timeout, `run()` stops a command after 30 seconds, so set `timeoutMs` / `timeout_seconds` on installs, builds and tests. |
| Home directory | The Blaxel base image uses `/blaxel`. Superserve sandboxes use `/home/user`. Update hard-coded paths. |
| Resources | Set `vcpu` and `memoryMib` on the template, not on the sandbox. |
| Preview ports | Bind servers to `0.0.0.0` instead of `$HOST`. Each published port gets its own URL. A new port is public by default. Publish with `access: "private"` and send a preview token to keep a port protected. Serve on a port from 1024 to 65535. |
| Process state | The migration script moves files, not memory. Take a Superserve snapshot after you restart services. |
