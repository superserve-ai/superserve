Install the SDK, set your API key, and create a sandbox.

Start free, no card required. A new account gets a limited free trial for its first sandbox. Add a card and choose a plan to continue once the trial credit is used up.

## 1. Install the SDK

<CodeGroup>
```bash npm
npm install @superserve/sdk
```

```bash pip
pip install superserve
```
</CodeGroup>

## 2. Set your API key

Sign up for free in the [Superserve Console](https://console.superserve.ai?utm_source=docs&utm_medium=link), no card required. Grab your API key and export it.

```bash
export SUPERSERVE_API_KEY=ss_live_...
```

See [Get an API key](/api-key) for more options.

## 3. Create a sandbox and run a command

<CodeGroup>
```typescript TypeScript
import { Sandbox } from "@superserve/sdk"

const sandbox = await Sandbox.create({ name: "quickstart" })

const result = await sandbox.commands.run("echo 'Hello from Superserve!'")
console.log(result.stdout)

await sandbox.files.write("/tmp/hello.txt", "Hello, world!")
const content = await sandbox.files.readText("/tmp/hello.txt")
console.log(content)

await sandbox.kill()
```

```python Python
from superserve import Sandbox

sandbox = Sandbox.create(name="quickstart")

result = sandbox.commands.run("echo 'Hello from Superserve!'")
print(result.stdout)

sandbox.files.write("/tmp/hello.txt", "Hello, world!")
content = sandbox.files.read_text("/tmp/hello.txt")
print(content)

sandbox.kill()
```
</CodeGroup>

## 4. Run it

Save the TypeScript as `index.mts` or the Python as `main.py`, then run it:

<CodeGroup>
```bash TypeScript
npx tsx index.mts
```

```bash Python
python3 main.py
```
</CodeGroup>

<Note>
The TypeScript uses top-level `await`, which Node only allows in ES modules. The `.mts` extension makes the file one. To use `.ts` instead, set `"type": "module"` in your `package.json`.
</Note>
