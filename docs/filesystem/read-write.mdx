Use `sandbox.files` to move data in and out of a sandbox. The SDK handles data-plane routing and authentication transparently.

<CodeGroup>
```typescript TypeScript
await sandbox.files.write("/app/config.json", '{"key": "value"}')

const text = await sandbox.files.readText("/app/config.json")
console.log(text)
```

```python Python
sandbox.files.write("/app/config.json", '{"key": "value"}')

text = sandbox.files.read_text("/app/config.json")
print(text)
```
</CodeGroup>

<Note>
Using `AsyncSandbox`? The same `files` methods are there, awaitable.
</Note>

## Write binary content

`write()` accepts strings or raw bytes. Parent directories are created automatically.

<CodeGroup>
```typescript TypeScript
import { readFileSync } from "node:fs"

const buffer = readFileSync("./local-image.png")
await sandbox.files.write("/app/image.png", buffer)

await sandbox.files.write("/app/data.bin", new Uint8Array([1, 2, 3, 4]))
```

```python Python
with open("local-image.png", "rb") as f:
    sandbox.files.write("/app/image.png", f.read())

sandbox.files.write("/app/data.bin", bytes([1, 2, 3, 4]))
```
</CodeGroup>

## Read as bytes or text

- `read()` returns raw bytes (`Uint8Array` in TypeScript, `bytes` in Python)
- `readText()` / `read_text()` returns a UTF-8-decoded string

<CodeGroup>
```typescript TypeScript
const bytes: Uint8Array = await sandbox.files.read("/app/image.png")

const text: string = await sandbox.files.readText("/app/config.json")
```

```python Python
data: bytes = sandbox.files.read("/app/image.png")

text: str = sandbox.files.read_text("/app/config.json")
```
</CodeGroup>

## Download size limit

`read()` and `downloadDir()` / `download_dir()` stop at 2 GiB by default. A
larger download fails with `ValidationError`. Pass `maxBytes` / `max_bytes` to
set a different limit for one call, for example to reject unexpectedly large
files early. For `downloadDir()`, the limit applies to the size of the ZIP
archive. `readText()` / `read_text()` always uses the 2 GiB default.

<CodeGroup>
```typescript TypeScript
import { ValidationError } from "@superserve/sdk"

try {
  const bytes = await sandbox.files.read("/app/results/output.bin", {
    maxBytes: 1024 * 1024, // 1 MiB
  })
} catch (err) {
  if (err instanceof ValidationError) {
    console.log(err.message) // Download exceeds the maximum size of 1048576 bytes
  }
}
```

```python Python
from superserve import ValidationError

try:
    data = sandbox.files.read("/app/results/output.bin", max_bytes=1024 * 1024)  # 1 MiB
except ValidationError as err:
    print(err)  # Download exceeds the maximum size of 1048576 bytes
```
</CodeGroup>

## Directories

The `files` methods work on one file at a time. For a whole directory:

- **List** — call the REST API, as shown below.
- **Upload** — write a tar archive, then extract it in the sandbox.
- **Download** — use [`downloadDir()` / `download_dir()`](#download-a-directory-as-a-zip).

### List a directory

`GET /sandboxes/{sandbox_id}/files?path=<dir>` returns one level of the
directory. Each entry has `name`, `is_dir`, `size`, and `modified_unix`. Send
your API key in the `X-API-Key` header. A paused sandbox resumes for the call.

Send the request to the API URL for your key's region, the same URL the SDK
uses. Keys that start with `ss_live_usw_` use `https://api-usw.superserve.ai`.
Other keys use `https://api.superserve.ai`. `SUPERSERVE_BASE_URL`, when set,
overrides both. In TypeScript, `resolveConfig()` returns this URL.

<CodeGroup>
```typescript TypeScript
import { resolveConfig } from "@superserve/sdk"

const { baseUrl, apiKey } = resolveConfig()
const res = await fetch(
  `${baseUrl}/sandboxes/${sandbox.id}/files?path=${encodeURIComponent("/app")}`,
  { headers: { "X-API-Key": apiKey } },
)
if (!res.ok) throw new Error(await res.text())

const { entries } = await res.json()
for (const entry of entries) {
  console.log(entry.is_dir ? `${entry.name}/` : entry.name, entry.size)
}
```

```python Python
import os

import httpx  # installed with the superserve package

api_key = os.environ["SUPERSERVE_API_KEY"]
base_url = os.environ.get("SUPERSERVE_BASE_URL") or (
    "https://api-usw.superserve.ai"
    if api_key.startswith("ss_live_usw_")
    else "https://api.superserve.ai"
)

res = httpx.get(
    f"{base_url}/sandboxes/{sandbox.id}/files",
    params={"path": "/app"},
    headers={"X-API-Key": api_key},
)
res.raise_for_status()

for entry in res.json()["entries"]:
    print(entry["name"] + ("/" if entry["is_dir"] else ""), entry["size"])
```
</CodeGroup>

For a recursive listing, run a command, for example
`sandbox.commands.run("find /app -type f")`.

### Upload a directory

Pack the local directory into a tar archive, write the archive to the
sandbox, and extract it with a command.

<CodeGroup>
```typescript TypeScript
import { execFileSync } from "node:child_process"
import { readFileSync } from "node:fs"

execFileSync("tar", ["-czf", "data.tar.gz", "-C", "./data", "."])
await sandbox.files.write("/app/data.tar.gz", readFileSync("data.tar.gz"))

const result = await sandbox.commands.run(
  "mkdir -p /app/data && tar -xzf /app/data.tar.gz -C /app/data && rm /app/data.tar.gz",
)
if (result.exitCode !== 0) throw new Error(result.stderr)
```

```python Python
import io
import tarfile

buf = io.BytesIO()
with tarfile.open(fileobj=buf, mode="w:gz") as tar:
    tar.add("./data", arcname=".")
sandbox.files.write("/app/data.tar.gz", buf.getvalue())

result = sandbox.commands.run(
    "mkdir -p /app/data && tar -xzf /app/data.tar.gz -C /app/data && rm /app/data.tar.gz"
)
if result.exit_code != 0:
    raise RuntimeError(result.stderr)
```
</CodeGroup>

### Download a directory as a zip

`downloadDir()` / `download_dir()` exports a whole directory as a ZIP archive —
useful for pulling out logs, build artifacts, or results in one call. It returns
the raw zip bytes; large directories can exceed the default 30s timeout, so pass
a longer `timeoutMs` / `timeout` when needed.

<CodeGroup>
```typescript TypeScript
import { writeFileSync } from "node:fs"

const zip = await sandbox.files.downloadDir("/app/results", {
  timeoutMs: 120_000,
})
writeFileSync("results.zip", zip)
```

```python Python
zip_bytes = sandbox.files.download_dir("/app/results", timeout=120)
with open("results.zip", "wb") as f:
    f.write(zip_bytes)
```
</CodeGroup>

## Path rules

Paths passed to `files.*` methods must:

- **Start with `/`** - only absolute paths are accepted
- **Contain no `..` segments** - no traversal

Parent directories are created automatically on write - you don't need to `mkdir -p` first.
