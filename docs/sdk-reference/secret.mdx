`Secret` manages credentials Superserve attaches to outbound requests; `Provider` lists the built-in shortcuts. Python ships both sync (`Secret`, `Provider`) and async (`AsyncSecret`, `AsyncProvider`) variants with identical method names.

## Import

<CodeGroup>
```typescript TypeScript
import { Secret, Provider } from "@superserve/sdk"
```

```python Python
from superserve import Secret, Provider
# Async variants:
from superserve import AsyncSecret, AsyncProvider
```
</CodeGroup>

The SDK reads `SUPERSERVE_API_KEY` from the environment by default; pass `apiKey` / `api_key` to override.

## Factory methods

### `Secret.create`

Create a secret. Provide either a `provider` shortcut **or** a custom `auth` config with `hosts` — they're mutually exclusive.

<CodeGroup>
```typescript TypeScript
// Provider shortcut.
await Secret.create({ name: "openai-prod", value: key, provider: "openai" })

// Custom auth.
await Secret.create({
  name: "internal-api",
  value: token,
  hosts: ["api.internal.example.com"],
  auth: { type: "api-key", header: "X-Api-Key" },
})
```

```python Python
Secret.create(name="openai-prod", value=key, provider="openai")

Secret.create(
    name="internal-api",
    value=token,
    hosts=["api.internal.example.com"],
    auth={"type": "api-key", "header": "X-Api-Key"},
)
```
</CodeGroup>

**Options:**

| Option | Type | Description |
|---|---|---|
| `name` | `string` | **Required.** Unique secret name. |
| `value` | `string` | **Required.** The credential. Encrypted on the platform; never returned. |
| `provider` | `string` | A built-in shortcut (see [`Provider.list`](#provider-list)). Mutually exclusive with `auth` / `hosts`. |
| `auth` | [`SecretAuth`](#secretauth) | Custom auth config. Requires `hosts`. Examples for each type: [Custom secrets](/secrets/create#custom-secrets). |
| `hosts` | `string[]` | Upstream hosts the credential may authenticate. Required with `auth`. |

Returns a `Secret`.

### `Secret.get`

Fetch an existing secret by name. Returns a `Secret`.

<CodeGroup>
```typescript TypeScript
const secret = await Secret.get("openai-prod")
```

```python Python
secret = Secret.get("openai-prod")
```
</CodeGroup>

### `Secret.list`

List all secrets for the team. Returns an array of [`SecretInfo`](#secretinfo).

<CodeGroup>
```typescript TypeScript
const secrets = await Secret.list()
```

```python Python
secrets = Secret.list()
```
</CodeGroup>

### `Secret.deleteByName` / `Secret.delete_by_name`

Delete a secret by name. Idempotent. Revokes the secret everywhere it's bound — bound stand-in tokens stop working, usually within seconds. Propagation is best-effort, so a sandbox can keep using the credential for up to about a minute.

<CodeGroup>
```typescript TypeScript
await Secret.deleteByName("openai-prod")
```

```python Python
Secret.delete_by_name("openai-prod")
```
</CodeGroup>

## Methods on `secret`

### `rotate`

Replace the value. Bound sandboxes keep their env var; the new value is used on subsequent requests, usually within seconds. Propagation is best-effort, so a sandbox can keep sending the old value for up to about a minute. Returns the updated `Secret`.

<CodeGroup>
```typescript TypeScript
await secret.rotate(newValue)
```

```python Python
secret.rotate(value=new_value)
```
</CodeGroup>

### `getAudit` / `get_audit`

Requests made with this secret, across all sandboxes, newest first. Returns an array of [`ProxyAuditEvent`](#proxyauditevent).

<CodeGroup>
```typescript TypeScript
const events = await secret.getAudit({ limit: 50, status: "4xx" })
```

```python Python
events = secret.get_audit(limit=50, status="4xx")
```
</CodeGroup>

| Option | Type | Description |
|---|---|---|
| `limit` | `number` | Max events to return. Default `100`, maximum `1000`. |
| `before` | `number` | Cursor — return events older than this event `id`. |
| `status` | `"2xx" \| "3xx" \| "4xx" \| "5xx" \| "errors"` | Filter by status class. `"errors"` matches every status of `400` or higher, including errors returned by the upstream service. |

### `getSandboxes` / `get_sandboxes`

Sandboxes this secret is currently bound to. Returns an array of [`SecretSandboxBinding`](#secretsandboxbinding).

<CodeGroup>
```typescript TypeScript
const bindings = await secret.getSandboxes()
```

```python Python
bindings = secret.get_sandboxes()
```
</CodeGroup>

### `getInfo` / `get_info` · `delete`

`getInfo()` re-fetches the latest [`SecretInfo`](#secretinfo); `delete()` removes this secret (idempotent).

<CodeGroup>
```typescript TypeScript
const info = await secret.getInfo()
console.log(info.name, info.hosts, info.lastUsedAt)

await secret.delete()
```

```python Python
info = secret.get_info()
print(info.name, info.hosts, info.last_used_at)

secret.delete()
```
</CodeGroup>

## Async (Python)

`AsyncSecret` and `AsyncProvider` have the same methods as `Secret` and `Provider`. Every method is a coroutine.

```python
import asyncio
import os

from superserve import AsyncProvider, AsyncSecret


async def main():
    providers = await AsyncProvider.list()

    secret = await AsyncSecret.create(
        name="openai-prod", value=os.environ["OPENAI_API_KEY"], provider="openai"
    )
    secret = await secret.rotate(value=os.environ["NEW_OPENAI_API_KEY"])
    info = await secret.get_info()
    events = await secret.get_audit(limit=50, status="errors")
    bindings = await secret.get_sandboxes()
    await AsyncSecret.delete_by_name("openai-prod")


asyncio.run(main())
```

## Types

### `SecretInfo`

| Field | Type |
|---|---|
| `id` | `string` |
| `name` | `string` |
| `authType` / `auth_type` | `"bearer" \| "basic" \| "api-key" \| "custom" \| "per_host"` |
| `authConfig` / `auth_config` | `Record<string, unknown>` — the stored [`SecretAuth`](#secretauth) fields, for example `{ header: "X-Api-Key" }`; `{}` for `bearer`. A per-host secret uses the key `per_host` in both SDKs. |
| `providerShortcut` / `provider_shortcut` | `string \| undefined` |
| `hosts` | `string[]` |
| `createdAt` / `created_at` | `Date` / `datetime` |
| `updatedAt` / `updated_at` | `Date` / `datetime` |
| `lastUsedAt` / `last_used_at` | `Date \| undefined` |

### `SecretAuth`

The `auth` option of [`Secret.create`](#secret-create): one rule for every host, or a list of per-host rules. In TypeScript it is the `SecretAuth` type. In Python it is a plain `dict` with the same keys, except that the per-host list is `per_host` instead of `perHost`.

Each rule type accepts only its own fields. A missing required field, or a field from another type, fails with `ValidationError`.

#### `bearer`

Sends `Authorization: Bearer <value>`.

| Field | Type | Description |
|---|---|---|
| `type` | `"bearer"` | **Required.** No other fields. |

#### `basic`

Sends `Authorization: Basic <base64(username:value)>`. The secret value is the password.

| Field | Type | Description |
|---|---|---|
| `type` | `"basic"` | **Required.** |
| `username` | `string` | Fixed username. It replaces the username in the request. When not set, the username in the request is kept, or `x` is used when the request has none. |

#### `api-key`

Sends `<header>: <prefix><value>`.

| Field | Type | Description |
|---|---|---|
| `type` | `"api-key"` | **Required.** |
| `header` | `string` | **Required.** Header name, for example `"X-Api-Key"`. |
| `prefix` | `string` | Text before the value, for example `"Token "`. Code in the sandbox must send the same prefix before the stand-in token. |

#### `custom`

Sends every header in `headers`, with `{{ value }}` replaced by the secret value.

| Field | Type | Description |
|---|---|---|
| `type` | `"custom"` | **Required.** |
| `headers` | `Record<string, string>` / `dict[str, str]` | **Required.** Header name to value template. Up to 8 headers. Every template must contain `{{ value }}`. |

#### Per-host rules

Picks a rule by the upstream host of the request.

| Field | Type | Description |
|---|---|---|
| `perHost` / `per_host` | `Array<SecretAuthRule & { hosts: string[] }>` / `list[dict]` | **Required.** 1 to 16 rules. Each rule is one of the rule types above, plus `hosts`. |
| `hosts` (in each rule) | `string[]` / `list[str]` | **Required.** Hosts this rule applies to. Each host must also be in the top-level `hosts` of `Secret.create`. A host can be in only one rule. |

<CodeGroup>
```typescript TypeScript
import type { SecretAuth } from "@superserve/sdk"

const auth: SecretAuth = {
  perHost: [
    { hosts: ["api.github.com"], type: "bearer" },
    { hosts: ["github.com"], type: "basic", username: "x-access-token" },
  ],
}
```

```python Python
auth = {
    "per_host": [
        {"hosts": ["api.github.com"], "type": "bearer"},
        {"hosts": ["github.com"], "type": "basic", "username": "x-access-token"},
    ]
}
```
</CodeGroup>
